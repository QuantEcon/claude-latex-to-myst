# Contraction Theorem

::: theorem
[]{#thm:contraction label="thm:contraction"}

If $T$ is a contraction on a complete metric space, then $T$ has a unique fixed point.
:::

::: proof
By Banach. Apply [\[thm:contraction\]](#thm:contraction){reference-type="ref" reference="thm:contraction"} iteratively.
:::
