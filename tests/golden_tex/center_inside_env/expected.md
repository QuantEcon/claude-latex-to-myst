# Orders

```{prf:example}
:label: eg-ppor

The **pointwise order** $\leq$ on $\RR^\Xsf$ is defined as follows:

given $u, v$ in $\RR^\Xsf$, set $u \leq v$ if $u(x) \leq v(x)$ for all $x \in \Xsf$.
```


A standalone centered line also unwraps:

$k \geq K$ implies every $v_k$-greedy policy is optimal.
