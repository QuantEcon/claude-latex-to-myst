\section{Orders}

\begin{example}\label{eg:ppor}
    The \textbf{pointwise order} $\leq$ on $\RR^\Xsf$ is defined as follows:
    %
    \begin{center}
        given $u, v$ in $\RR^\Xsf$, set
        $u \leq v$ if $u(x) \leq v(x)$  for all $x \in \Xsf$.
    \end{center}
\end{example}

A standalone centered line also unwraps:

\begin{center}
    $k \geq K$ implies every $v_k$-greedy policy is optimal.
\end{center}
